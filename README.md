# Einbürgerung Trainer – Cham & Zug

Eine vollkommen offline-fähige Progressive Web App (PWA) zur Vorbereitung auf das Einbürgerungsgespräch bei der Bürgergemeinde Cham und dem Kanton Zug.

## Highlights
- **100% Offline-fähig**: Service Worker Caching & IndexedDB Local Storage.
- **SM-2 Spaced Repetition Algorithm**: Intelligente Karteikarten-Wiederholung.
- **Audio Walking Mode**: Freihändiges Lernen beim Spazierengehen.
- **Bürgerrat Interview Simulation**: Mit Mikrofon-Aufnahme & Selbstbewertung.
