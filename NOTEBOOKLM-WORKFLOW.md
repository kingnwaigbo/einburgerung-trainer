# NotebookLM zu PWA Workflow Anleitung

## Schritt 1: Vorbereitung
1. Öffnen Sie Ihr NotebookLM Notebook ("Gemeinde" oder "Kanton").
2. Kopieren Sie den Inhalt der Datei `notebooklm-gemeinde-prompt.txt`.

## Schritt 2: Extraktion ausführen
1. Fügen Sie den Prompt in das Eingabefeld von NotebookLM ein.
2. Kopieren Sie die generierte JSON-Antwort.

## Schritt 3: In PWA Importieren
1. Öffnen Sie die **Einbürgerung Trainer PWA** auf Ihrem S23 Ultra.
2. Gehen Sie auf ⚙️ **Einstellungen** -> **JSON Datei Wählen**.
3. Importieren Sie die Datei. Alle Daten stehen sofort 100% offline zur Verfügung!
